@ABOUT:
This repository is not a professional tool for pentesting. It is just a self-made project for improving network understanding!

"RefactoredScanner" is a Python-based network utility made to check for open ports,
craft custom payloads, and determine service versions and OS types.

Future plans: implement "closed" and "filtered" port state detection; finish payload crafting; improve service and OS detection.

Start the main.py file with sudo to run the scanner (root privileges are required for Scapy!).
